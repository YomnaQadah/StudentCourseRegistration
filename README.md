# Student Course Registration System

## Project Description

A simple web-based Student Course Registration System
developed using HTML, CSS, and JavaScript.

## Features

1. Add students.
2. Add courses.
3. Display available courses.
4. Register students in courses.
5. Display courses registered by each student.
